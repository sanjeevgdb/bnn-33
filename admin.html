Connect to your GitHub site

How do I get an access token?
  1. On github.com, open your profile picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Tap Generate new token. Name it bnn33 admin and set Expiration to 1 year.
  3. Under Repository access, choose Only select repositories and pick bnn-33.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Tap Generate token, copy it (it starts with github_pat_) and paste it above.

The token is saved only in this browser on this phone. Never share it. It can change only the bnn-33 repository.
